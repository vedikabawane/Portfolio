# Vedika Bawane — Software Developer Portfolio

A modern, high-aesthetic developer portfolio built from scratch for **Vedika Bawane**, based entirely on her resume credentials.

---

## 🌟 Key Highlights & Design Identity
- **Distinct Aesthetic Theme**: Designed with an **Obsidian Velvet & Radiant Aurora** color palette (`#07080e`, electric rose-pink `#ff2a5f`, electric violet `#8b5cf6`, and luminous mint `#00f5a0`) with deep frosted glass cards, dynamic ambient orbs, and clean typography (`Syne` display + `Plus Jakarta Sans` body + `JetBrains Mono` code).
- **Interactive Code Terminal**: Features live interactive code tabs (`developer.py`, `skills.json`, `routes.py`) showcasing Python, Flask, and REST API architectures with one-click code copy.
- **Police Bharati EdTech Platform Simulator**:
  - Interactive modal demonstrating the **Marathi-First Police Bharati Learning Platform** (built with Flask, SQLAlchemy, MySQL, and JWT authentication).
  - Includes an interactive practice quiz in Marathi with instant evaluation, explanations, and student score tracking.
  - Interactive student dashboard preview (Rank #142, Test History, and Physical Fitness tracking).
- **Campus Placement Management System Showcase**:
  - Interactive modal simulating Training & Placement Officer (TPO) workflows, student registration, dynamic drive eligibility filtering, and application status tracking.
- **Embedded CodSoft Calculator**:
  - A functional, working retro-modern calculator directly inside the browser demonstrating DOM calculation logic from Vedika's internship at CodSoft.
- **Complete In-Browser ATS Resume Modal**:
  - Full ATS-compatible resume viewer matching the exact resume structure.
  - One-click **Print / Save PDF** action formatted with custom print CSS.
  - One-click "Copy Resume Text" button.
- **Interactive Contact Section**:
  - Direct copy buttons for email (`vedikabawane70@gmail.com`) and phone (`9309030556`).
  - Direct link to LinkedIn profile.
  - Validated contact form with celebratory confetti animation on submission.

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite 8
- **Styling**: Pure Vanilla CSS (Design system with CSS variables, frosted glassmorphism, glowing borders, and responsive grid)
- **Icons**: Lucide React
- **Effects**: Canvas Confetti

---

## 🚀 Running Locally

1. Navigate to the folder:
   ```bash
   cd vedika_portfolio
   ```

2. Install dependencies (already installed):
   ```bash
   npm install
   ```

3. Start the Vite development server:
   ```bash
   npm run dev
   ```

4. Build production bundle:
   ```bash
   npm run build
   ```
